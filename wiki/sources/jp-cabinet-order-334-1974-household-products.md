# Japan Cabinet Order No. 334 of 1974, designated harmful substances

This is the Cabinet Order that designates substances under Article 2(2) of the Act on Control of Household Products Containing Harmful Substances (Cabinet Order No. 334 of 1974), as printed from the e-Gov statute page. The print is the official HTML page saved as PDF. Antimony is not on the designated list.

## Key numbers

The order prints a closed list of designated harmful substances. The list includes formaldehyde and organic mercury compounds, among others. It does not name antimony. No antimony concentration, migration limit, or content limit is printed. The value is blank because the text sets none. The supplementary provision states that the order takes effect from 1 October 1974. Later amendments are those incorporated in the e-Gov text that was printed. This page does not assign an amendment number that the two-page print does not make explicit in a way that changes the antimony finding.

## Methods (brief)

The file is a print of the e-Gov page, not a separately typeset ministry PDF. The finding is a checked absence: the designated-substance list does not include antimony, so this order sets no antimony limit for household products, including household textiles.

## Evidence fitness

The page supports a negative finding for this order only. It does not support a claim that no Japanese instrument anywhere regulates antimony. Other Japanese notices, including food-contact notices already on the metal page, are different instruments.

## Limitations

The implementing ministerial ordinance was not saved as this PDF. Absence from this order is not absence from every Japanese rule.
