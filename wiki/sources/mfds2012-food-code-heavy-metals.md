# MFDS 2012 - Korean Food Code heavy-metal limits

## Overview

This English PDF excerpt from Korea's Food Code Article 2 gives common standards and specifications for general foods. Its HMI-relevant section is the "Heavy Metal" subsection, which lists maximum residue limits for marine fish and shellfish and selected agricultural products.

## Key numbers

Values are in mg/kg.

| Marine fish and shellfish including mollusca, live basis, except deep-sea fishes, tunas, and spearfishes | tHg | 0.5 |

The same subsection states that provisional heavy-metal limits for dried fish, shellfish, and agricultural products apply with consideration of water-content changes during drying.

## Methods (brief)

This is a regulatory food-code excerpt, not a sampling report. It provides limits and food-code hygiene/specification requirements. It does not report analytical recoveries, LODs, or occurrence sample values.
