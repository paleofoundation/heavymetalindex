# Gajek et al. 2021, wine by type, white column only

Gajek and colleagues measured elements in 180 wines. Table 7 splits red, white, and rose. Only the white column is used. The certified reference material was TMDA 64. No recovery percentage is printed. Arsenic and aluminum were not measured. Chromium is 52Cr, not hexavalent.

## Key numbers

Table 7 white, N = 75, µg/L.

| Metal | Mean | Median |
| --- | --- | --- |
| Chromium | 59.41 | 45.33 |
| Nickel | 41.86 | 38.41 |
| Cadmium | 9.416 | 4.200 |
| Lead | 41.98 | 38.02 |
| Tin | 28.1 | below LOD |

Mercury was not detected in any of 180 wines. That statement is not color-split, so it is not entered as a white-wine value.

## Methods (brief)

ICP-ToF-MS for the metals above. Cold-vapor AAS for mercury. Three measurements per sample are described for the all-sample table.

## Evidence fitness

The white column supports a white-wine note for chromium, nickel, cadmium, lead, and tin. It does not support a white-only mercury result.

## Limitations

No recovery percentage. Tin median is below the limit of detection, and a numeric tin LOD is not printed in the main text.
