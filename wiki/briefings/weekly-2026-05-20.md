## Cochrane comparison

### 1. Verdict

**Approaching Cochrane-class.** The architectural commitments (per-claim provenance, deterministic pooling math in code, git-versioned source pages, drift-direction lint, editorial firewall from HMTc) put this wiki on the Cochrane trajectory in ways most agency reference works are not — but corpus completeness is the binding constraint: with ~1,010 ingested sources against a stated 23,000-paper target (~4% coverage), 367 BLOCKED pool entries, and no published PRISMA-style search-and-screen log, a hostile reviewer can credibly argue the corpus has not been exhaustively identified, which is the foundational Cochrane claim.

### 2. Dimensional grading

**Corpus completeness — 2/5.** ~1,010 / 23,000 papers (~4%); 367 BLOCKED pool cells indicate the literature is not yet sufficient for synthesis in most rows. No PRISMA flow diagram, no published search strings, no externally auditable screened-but-excluded log. Cochrane baseline: 4-5 (full search strategy across ≥3 databases plus grey literature, all decisions logged). EFSA: ~4. Currently below FDA Closer to Zero on this axis because Closer to Zero at least publishes its corpus boundaries.

**Source provenance — 4/5.** Per-claim cite-keys, routing audit with only 13 unresolved entries against 1,010 sources, raw/ immutable, source pages preserved verbatim, lint catches provenance gaps as build failures. This is the wiki's strongest dimension and matches Cochrane's baseline. Loses one point because provenance for synthesis claims (which sources contributed to a `typical_ppb` value) is page-resident rather than emitted as a standalone PRISMA-style citation table per synthesized claim.

**Methodology transparency — 4/5.** CLAUDE.md, docs/standards-methodology.md, and hmtc-governing-principles.md publicly declare the P97/P45 row-pass calibration, native-basis convention, moment-matching pseudo-sample expansion, and the rationale tagging (literature-baseline / regulatory-alignment / precautionary / feasibility-driven). Pooling math lives in code, not staff judgment. Below Cochrane only because the synthesis-mode rules (2-source initial population, doubling triggers, top-5-cited prior contributors in incremental mode) are not yet defended in a peer-reviewed methods paper or pre-registered protocol document with a DOI.

**Replicability — 3/5.** Mechanisms are right: git history reconstructs any page on any date, raw/ is append-only, pooling is deterministic, basis-conversion logged per source. But only 39 cells have been synthesized (28 null→low, 0 promotions to high from prior states), and synthesis depends on a corpus that is 4% complete — so an external reviewer re-running the pipeline today would reproduce the current values exactly but could not verify that the current values reflect the literature. Re-derivability requires both reproducible methods AND a complete-enough corpus; this has the first, not the second.

**Currency — 4/5.** 985 commits, live OpenAlex ingestion (17 PDFs in 7 days), per-cell `last_reviewed` and `last_full_resynthesis` fields, doubling-trigger resynthesis. This exceeds Cochrane's typical 2-5 year update cycle and exceeds EFSA monograph cadence. Loses a point because OpenAlex pull rate (17/week) is too slow to close the corpus-completeness gap before drift compounds — currency of a partial corpus is currency of a partial corpus.

**Independence — 3/5.** Architectural separation is real (separate domains, no HMTc brand mentions in wiki, drift-direction lint check, explicit Part 2 firewall rule). But Paleo Foundation operates both the wiki and the certifier — Cochrane's gold standard is external editorial independence with declared COI for every contributor. A plaintiff's expert will note that the "independent reference that the certifier happens to operate" framing is operator-asserted, not externally verified. The dimension is structurally capped at 3 until an external editorial board signs off on synthesis pages.

### 3. Improvement vectors (targeting corpus completeness, the binding weakness)

**Vector 1 — Stand up a PRISMA-style screen-and-exclude registry.** Extend the autonomy loop with a daily query runner that hits OpenAlex, PubMed, EFSA Knowledge Junction, and FDA's analytical-results portal for every (metal × ingredient × matrix) tuple in `data/evidence/`, logs every hit to `data/evidence/screened-sources.csv` with one of `included` / `excluded:<reason>` / `pending`, and emits a per-category PRISMA flow diagram (records identified → screened → eligible → included) as a generated page under `wiki/methodology/prisma/`. This converts the corpus-completeness claim from "we have 1,010 papers" to "we screened N and the inclusion rationale for each is auditable" — which is the Cochrane-defining move. Concrete build step: `tools/autonomy/run-corpus-search.mjs` + `tools/evidence/build-prisma-page.mjs` + a new evidence file `screened-sources.csv` with columns `[source_id, query_tuple, openalex_id, doi, decision, reason, decided_at]`.

**Vector 2 — Build a corpus-gap dashboard wired into the ingest priority queue.** For every cell in `contamination_profile`, compute target_N (e.g., 20 primary studies for `confidence: high`, 8 for `medium`, 3 for `low`), current_N, and the ranked deficit. Persist to `data/evidence/corpus-gaps.csv`, rank by (HMTc commercial priority × deficit × pool-state BLOCKED-ness), and feed the top-N rows into the next OpenAlex query batch. This closes the loop between the 367 BLOCKED pool entries and the 17/week ingest rate by making the autonomy loop pull literature against named gaps rather than against whatever Karen happens to drop in raw/. Concrete build step: `tools/autonomy/compute-corpus-gaps.mjs` reading `wiki/ingredients/*.md` and `tools/evidence/pool-status.json`, emitting a ranked queue consumed by Vector 1's query runner.

**Vector 3 — Emit a per-synthesized-cell evidence citation table.** When the synthesis pass writes a `contamination_profile` cell, also write a sibling artifact at `wiki/ingredients/<ingredient>.evidence.<metal>.md` listing every contributing source, weight, included/excluded status, conversion-basis applied, and the exact value extracted from each — the "table 1" of a Cochrane review. Lint fails if any synthesized cell lacks the sibling artifact. This converts page-resident provenance (4/5) into citation-table provenance (5/5) and makes any single synthesis claim independently re-derivable by an external reviewer with a calculator. Concrete build step: extend the synthesis pipeline in `tools/evidence/` to emit the sibling markdown alongside the cell update, and add a lint rule in the existing audit suite.
