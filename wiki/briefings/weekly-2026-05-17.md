## Cochrane comparison

### 1. Verdict

**Not yet Cochrane-class.** The scaffolding is unusually strong for a wiki — per-claim provenance via routing, git-level reconstructibility, an architecturally enforced firewall between evidence layer and certification deliverable, and locked standards math that lives outside `wiki/` — but the execution is narrow and unverified: 945 source pages is a small fraction of the heavy-metals food literature, synthesis lags ingest roughly 50:1 (15 cells written against 774 new sources this week), 295 pool cells are BLOCKED, and no external review has been executed yet. Cochrane authority comes from exhaustive search + transparent screening + dual extraction + RoB grading + GRADE certainty + public peer review on every question; HMI today has the infrastructure to host that workflow but does not yet perform it.

### 2. Dimensional grading

### 3. Improvement vectors

Targeting the two weakest dimensions (corpus completeness, replicability), in autonomy-loop-executable form:

**(a) Build a per-cell PRISMA coverage audit and publish the flow diagram.** Extend `tools/evidence/build-routing-audit.mjs` (or sibling tool) to, for every `(ingredient, metal)` cell whose status is not `pending`, query OpenAlex/PubMed for the cell's canonical search string, diff candidate-universe against included-sources, and emit `data/evidence/coverage/<ingredient>-<metal>.json` plus a rendered flow diagram (records identified / screened / excluded-with-reason / included / contributing to pool). The autonomy loop runs it on the same cadence as the routing audit. This makes the corpus-completeness gap *visible and ranked* so the ingest queue can prioritize the cells with the widest universe-vs-included delta; it also closes the single biggest replicability hole (a hostile reviewer can currently say "you don't know what you missed," and after this they can't). Lint failure: any `populated` cell missing a coverage diagram.

**(b) Replace `evidence_tier: A/B/C` with a structured RoB 2.0-style block on every source page and propagate to GRADE-style cell certainty.** Add a `risk_of_bias` frontmatter block with explicit fields — sampling frame, analyte LOD/LOQ, blank/control handling, speciation method, sample size adequacy, conflict-of-interest disclosure — each rated `low / some_concerns / high / unclear` against documented criteria in `docs/risk-of-bias-rubric.md`. Re-run the structured extractor over all 945 sources to backfill. Modify the synthesis tool to (i) weight pool admission by RoB, (ii) emit a GRADE certainty per cell (`high / moderate / low / very low`) derived from the contributing-source RoB distribution, and (iii) refuse `confidence: high` unless ≥3 `low_risk_of_bias` A-tier sources back the cell. This is what brand legal will compare against in deposition; "evidence_tier: A" will not survive cross-examination, "RoB 2.0 low across five domains" will.

**(c) Pre-register protocols per synthesis cell before the pass runs.** Add a Phase to the synthesis trigger in CLAUDE.md Part 9: before any cell is written, the synthesis tool emits `wiki/protocols/<ingredient>-<metal>.md` capturing the search strings, databases queried, search date, inclusion/exclusion criteria applied, expected basis conversions, and the RoB threshold for admission. The cell's `last_full_resynthesis` links to the protocol commit SHA. A second synthesis pass that wants to deviate from the protocol must write a protocol amendment with a stated rationale, committed before the new synthesis. This converts methodology transparency from system-wide-only to per-question — the dimension along which Cochrane reviews score highest and HMI currently scores lowest within "transparency."

The three together lift replicability from 3 → 4 and corpus completeness from 2 → 3 within the existing autonomy loop, without requiring new human reviewers. External review (the brief at `docs/external-review-brief.md`) is the dimension-6 lift that takes independence from 4 → 5, but it is a billing-and-contracting workflow, not a build step.
