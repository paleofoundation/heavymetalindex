The qualifier: only 31 synthesis cells written this week and confidence distributions are null→low (22 of 31). The scaffolding is Cochrane-grade; coverage of synthesized claims is still partial, so the provenance graph is sparse in places.

**Methodology transparency — 4.5/5.** At or above Cochrane (4-5), above WHO monographs (~4-5), well above FDA Closer to Zero (~3). The P97/P45 lock with explicit 90/30 row-pass intent, the moment-matching pseudo-sample expansion rule, the native-basis convention, the regulatory-cap binding rule, and the four rationale tags (`literature-baseline` / `regulatory-alignment` / `precautionary` / `feasibility-driven`) are all open, documented in `docs/governance/hmtc-governing-principles.md`, and reproducible. Half-point deducted because the search strategy (which OpenAlex queries, which inclusion criteria, which exclusion rules) is not pre-registered in the same way the pooling math is locked.

**Replicability — 3/5.** Comparable to EFSA, below Cochrane (5). An external reviewer with the repo, the `raw/` directory, and the pooling code can re-derive every standard from sources. The gaps: no PROSPERO-equivalent registry of the search protocol per cell; auto-fetch is opportunistic against OpenAlex rather than systematic against MEDLINE+EMBASE+CENTRAL+grey literature with documented query strings; no second-reviewer extraction pass to surface discordances. A hostile expert can ask "why these 994 sources and not the 10,000 PubMed hits for `lead AND infant formula`?" and the wiki cannot point to a pre-registered exclusion log.

**Currency — 4/5.** Above Cochrane (4 — Cochrane reviews update every ~2 years). Daily ingest cycles, 675 new source pages this week, file-watcher-triggered routing, synthesis triggers on n_studies doubling and 2x contradiction events. The deduction is conditional: velocity is high but the underlying corpus is still small, so the synthesis being "current" is constrained by what has been ingested rather than what exists.

**Independence — 3.5/5.** The wiki/HMT&C firewall in CLAUDE.md Part 2 is architecturally enforced (separate domains, separate repos, separate epistemic registers, lint rules for silent threshold deviation), and the Part 19 rule that standards arithmetic lives in `data/workbench/` not `wiki/` is structurally sound. Above Cochrane on architectural separation, below Cochrane on operational separation: Cochrane reviews are authored by independent academic groups; this wiki is operated by the same Paleo Foundation that runs HMTc. A plaintiff's expert will probe this. The architectural firewall holds up under that probe better than most certifier-operated reference works (FDA Closer to Zero scores ~3 here), but not as well as fully independent academic systematic reviews.

### 3. Improvement vectors

Weakest dimension is **corpus completeness (2/5)**. Three executable build steps:

**(a) Pre-register a search protocol per (metal × matrix) cell.** Create `data/evidence/search-protocols/<metal>-<matrix>.md` with frontmatter capturing search date, database list (OpenAlex, PubMed, EFSA Knowledge Junction, FDA TDS), exact query strings, inclusion/exclusion criteria, expected hit count, retrieved count, and post-screening retained count. Extend the autonomy loop to refuse to mark a cell synthesizable until its protocol exists, has been executed, and the retained/expected ratio is logged. This converts the gap-driven wishlist from "fetch what we don't have" into "fetch what the protocol says exists." Directly attacks the "why these 994 sources" challenge.

**(b) Extend the gap-driven wishlist generator to emit a per-cell exhaustion estimate.** For each BLOCKED pool, query OpenAlex (and PubMed when API access lands) for the count of *candidate* papers matching the (metal × matrix × analyte-species) tuple, write the count to `data/evidence/cell-coverage-estimates.csv`, and compute `coverage_ratio = retrieved / candidate`. Make this the primary metric on the morning report rather than raw source count. A cell with 5 retrieved out of 200 candidates is honest about its hole; a cell with 5 retrieved and 6 candidates is honestly near-saturated. Turns the 306-BLOCKED number into a prioritized fetch queue.

**(c) Add a dual-independent extraction pass to the ingest pipeline.** When a source PDF is extracted into a source page, run a second independent extraction (different model temperature, different system prompt, different cite-key-blind framing) and write the discordance to `data/evidence/extraction-discordance.csv`. Cells with discordance > threshold (e.g., 2x divergence on `typical_ppb` extraction or any species/basis disagreement) block synthesis until human review. This mirrors Cochrane's two-reviewer rule, raises replicability from 3 to 4+, and produces an audit trail that explicitly survives "your extraction was wrong" challenges from hostile experts.
