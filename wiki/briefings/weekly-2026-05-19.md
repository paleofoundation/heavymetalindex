## Cochrane comparison

### 1. Verdict

**Approaching Cochrane-class** on architecture and provenance; **not yet Cochrane-class** on corpus completeness and synthesis replicability. The wiki has a Cochrane-grade firewall design (Part 2's two-direction drift rule), per-claim provenance enforced by lint, and a faster currency cadence than Cochrane achieves — but it lacks a pre-registered, reproducible search protocol and a deterministic synthesis pipeline, both of which a hostile expert would attack first.

### 2. Dimensional grading

**Corpus completeness — 2/5.** Cochrane baseline is ~5: PROSPERO-registered search strategies across MEDLINE/EMBASE/CENTRAL/grey literature with PRISMA flow diagrams. EFSA sits at ~4 with documented call-for-data plus literature scoping. This wiki has 995 source pages and a gap-driven wishlist, but no pre-registered (database, query string, date-range, screening criteria) tuples per (ingredient, metal) cell. With 305 BLOCKED pool states against 53 READY, the corpus is broad but the eligible-evidence subset is thin and the "we have reviewed the complete literature" claim cannot yet survive cross-examination — a plaintiff's expert will ask "show me the OpenAlex query, the date you ran it, the inclusion/exclusion screen, and the screened-out count," and only fragments of that are reconstructible today.

**Source provenance — 4/5.** Cochrane baseline ~5. This is the wiki's strongest dimension by design: every numerical claim must trace to a source page (Part 18 lint failure if not); the routing audit emits a deterministic (source → target page → route_kind) triple; raw/ is immutable; 955 commits give per-claim git-bisectable history. The half-point gap to Cochrane is that source-page extracted values are not yet structured down to (statistic-type, basis, censoring, n) records — the provenance link exists, but a reviewer auditing a synthesis claim still has to re-read the source markdown to verify the value, rather than seeing a structured extraction row.

**Methodology transparency — 4/5.** Cochrane baseline ~5 (Cochrane Handbook + per-review protocols). WHO monographs sit at ~4-5. This wiki publishes `docs/governance/hmtc-governing-principles.md`, locks the P97/P45 standards math with a public row-pass calibration rationale, and `docs/standards-methodology.md` carries pool admission rules. Stronger than FDA Closer to Zero (~3). The gap to Cochrane: the **synthesis** protocol (Part 9 — initial population, incremental update, full resynthesis) is documented at the workflow level but not at the analytical level. Cochrane reviewers can describe the exact GRADE rubric they used; the wiki's contradiction-arbitration rules and contributor-selection logic for incremental updates are described as "top 5 most-cited prior contributors," which is operational, not analytically rigorous.

**Replicability — 2/5.** Cochrane baseline ~5. The standards math is fully deterministic and lives in code (pooling, native-basis conversion, regulatory cap), which is excellent. But the synthesis pass that produces `contamination_profile` values on ingredient pages is LLM-driven: a session reads source markdown and writes synthesis prose plus structured fields. Two independent Claude sessions given the same source set will not produce byte-identical outputs. This is the dimension most exposed to hostile review — "your synthesis is non-reproducible by construction" is a defensible attack today.

**Currency — 5/5.** Cochrane baseline ~3 (multi-year revision cycles, frequently stale). 584 new source pages in 7 days, daily autonomy loop, synthesis triggered on routing-audit signal rather than manual reviewer initiative, n_studies-doubling resynthesis trigger. The wiki is faster than Cochrane by an order of magnitude and this is genuine strategic advantage, not soft scoring.

**Independence — 3/5.** Cochrane baseline ~5 (no commercial deliverable). The architectural separation (heavymetalindex.com vs heavymetaltested.com, Part 2 firewall, "the gap is the point" framing, rationale-tag lint for silent threshold deviation) is best-in-class for an industry-operated reference. But the wiki and HMTc share an operator (Paleo Foundation), and a hostile expert will note that the editorial firewall is policy-enforced rather than institutionally enforced. The lint catches silent drift; it does not eliminate the operator-overlap concern. This is below Cochrane and below WHO/EFSA; it is above any industry-association reference work.

### 3. Improvement vectors (targeting corpus completeness and replicability)

**(a) Pre-register and execute per-cell search protocols.** Add `tools/autonomy/run-cell-search-protocol.mjs` that, for each (ingredient, metal) cell, reads a versioned protocol file (`data/evidence/search-protocols/<ingredient>-<metal>.yml` declaring database, query, date range, screening criteria) and emits a PRISMA-style record per run: queries issued, result counts, deduplication outcome, inclusion/exclusion-screened counts, and final included-set hash. Persist to `data/evidence/prisma-runs.jsonl`. Generate `wiki/methodology/prisma-<ingredient>-<metal>.md` automatically. This converts "we did a comprehensive search" from a claim into a reproducible artifact and would raise corpus completeness from 2 → 4.

**(b) Replace markdown-driven synthesis with structured-extraction-driven synthesis.** Extend the routing/extraction layer to emit `data/evidence/extracted_observations.jsonl`, one record per source-reported value with fields (cite_key, analyte, statistic_type, value, basis, n, censoring, jurisdiction, matrix, year). Refactor `tools/evidence/build-synthesis.mjs` so the synthesis pass operates over this JSONL — not by re-reading source markdown — to compute `typical_ppb`, `p95_ppb`, and confidence. The LLM still writes the prose narrative on ingredient pages, but the numerical synthesis becomes byte-deterministic given the same JSONL. This raises replicability from 2 → 4 and closes the half-point gap on provenance.

**(c) Codify the synthesis protocol the way the standards math is codified.** Add `docs/synthesis-methodology.md` (peer to `docs/standards-methodology.md`) specifying: which sources are admitted per cell (the same admission rule as pool admission, or a documented divergence), the contradiction-arbitration algorithm (currently described as "re-read both in full"), the contributor-selection rule for incremental updates with explicit ranking math, confidence-level assignment criteria tied to n_studies and tier distribution, and a version table. Add a lint check that any synthesis page whose contributor set or value cannot be reproduced from the current methodology version fails the build. This raises methodology transparency from 4 → 5 and supports vector (b) by making the protocol the synthesis tool implements.
