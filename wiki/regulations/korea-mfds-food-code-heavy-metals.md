# Korea Food Code - heavy-metal limits

This page records the heavy-metal limits present in the local English Food Code excerpt ingested as [[sources/mfds2012-food-code-heavy-metals]]. Because the PDF is a 2012 excerpt, current-law use should verify against the current MFDS Food Code before legal application.

## Scope

The excerpt covers common standards and specifications for general foods. The HMI-relevant heavy-metal subsection covers marine fish, shellfish, and selected agricultural products.

## Exact limit and units

See [[sources/mfds2012-food-code-heavy-metals]] for the transcribed mg/kg limits. Key rows include tHg 0.5 mg/kg for marine fish and shellfish, MeHg 1.0 mg/kg for deep-sea fishes, tunas, and spearfishes, Pb 2.0 mg/kg and Cd 2.0 mg/kg for shellfish, and Pb/Cd limits from 0.05 to 0.3 mg/kg for selected crops.

## How tested
