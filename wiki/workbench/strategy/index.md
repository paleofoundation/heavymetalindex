# Workbench strategy index

Staff-only product strategy and design documents. Public wiki content lives elsewhere; this directory holds internal architectural docs that inform what gets built.

## Ask the Index

The free conversational interface to heavymetalindex.com. Three companion docs:

- [[workbench/strategy/ask-the-index-spec]] — strategy frame, design principles, hard guardrails, all nineteen features, MVP/Phase 2/Phase 3 sequencing, infrastructure dependencies, risks, open questions.
- [[workbench/strategy/ask-the-index-phases-2-3-design]] — build-deep UX, prompt architecture, data dependencies, edge cases, launch coordination, paid-service adjacencies, and success metrics per Phase 2 and Phase 3 feature.
- [[workbench/strategy/ask-the-index-current-state-gap]] — v0 implementation in fact, gap analysis against the MVP spec, four baked-in architectural decisions (certification firewall, TF-IDF retrieval, OpenAI direct vs Gateway, model selection), and the v0-grounded MVP work plan.

Read the gap doc first for any build work; it grounds the spec in v0 reality. Read the spec for strategic framing. Read the Phase 2/3 doc for post-MVP work.
