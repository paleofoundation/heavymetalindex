# Workbench standards snapshots

Staff-only index of the per-product percentile-arithmetic snapshots generated by `tools/evidence/apply-product-hmtc-evidence-summaries.mjs`. Each snapshot mirrors a public product-category page (linked) and carries the threshold-selection content (p10/p30/p50/p90/p95/p100, clean and dirty designation per Part 19, Path A/B status, n_a_tier, CC eligibility verdict, next-ingest target). The public side of each row lives at the linked product page; the snapshots regenerate end-to-end on every generator run.

Per OPERATING.md Part 2 and CLAUDE.md Part 19, percentile arithmetic is staff content, not public content. The workbench is the home for it; this index is the staff-side map.

## How a snapshot reads

Each snapshot is divided into three tables. The percentile arithmetic table shows p10 through p100 for the selected Path A dataset per analyte, plus n, source, and basis. The clean and dirty designation table shows the within-pair classification per analyte and the comparator basis. The CC eligibility and Path status table shows n_a_tier, Path A vs Path B vs blocked, CC eligibility verdict (at readiness bar, approaching, below), and the next-ingest target the gap report flagged.

The operational reminders at the bottom of each snapshot restate the standing rules: final HMT&C values do not exceed the lowest applicable regulatory cap, pooling requires basis matching, speciation is non-substitutable, and confidence ratings follow CLAUDE.md Part 6.

## How to regenerate

```bash
cd ~/Desktop/heavy-metal-index
export PATH="/opt/homebrew/opt/node@24/bin:$PATH"
node tools/evidence/apply-product-hmtc-evidence-summaries.mjs
```

Snapshots are rewritten end-to-end on each run; do not edit them by hand. The public-side block on each product page is updated in the same run from the same data source.
