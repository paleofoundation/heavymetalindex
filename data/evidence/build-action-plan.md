## How to use this plan

1. Pick the top action you have time for.
2. If it has a session prompt file, paste the contents into the appropriate session (Claude Code, Obsidian Claude, etc.). The prompt is self-contained — it names the files, the workflow, the don'ts, and the expected output.
3. If it has an `inline_action`, the orchestrator can execute it directly (v1 will auto-dispatch these).
4. After the action completes, regenerate the plan with `npm run plan` to see the next-most-valuable action.

The plan is the source of truth for what to work on next. TODO.md is the human-curated overlay for things that don't fit the orchestrator's signal vocabulary.
