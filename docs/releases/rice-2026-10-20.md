# Rice production release

The release starts from the live site's commit `50bc27a2e7d0e30ee23906ff96aec89a09050952` and adopts the approved Rice pilot. Other ingredient, metal and product manuscripts retain the live baseline. The shared Sources archive becomes a searchable catalogue; verified citation placement and discovery candidates remain separate. Twelve dependent source records carry the pilot's reviewed bibliographic and reporting corrections.

The approved Rice hero, byline, snapshot and right rail remain locked to `docs/contracts/reference-design/rice-2026-10-19/approved-chrome.json`. The frozen snapshot's historical reference count remains unchanged under that instruction. Scientific assessment remains partial, and relative positions do not represent safety thresholds.

## Build and deploy

Use `npm run build:rice-release` for this scoped release. It runs contract, FDA artifact, scope, source, integrity, firewall and component checks; rebuilds the source catalogue and public data manifests; renders the full site; runs all existing production postbuild checks; and verifies Rice's rendered contract, question anchors, findings, controls and locked chrome. The general `npm run build` additionally runs corpus-wide content writers and is a separate corpus refresh. Running those writers during this release was found to rewrite unrelated published manuscripts; those generated changes were restored before release.

`vercel.rice.json` preserves the production routing, functions, headers and redirects and selects the scoped command. Stage with `vercel build --prod --local-config vercel.rice.json`, then `vercel deploy --prebuilt --prod --skip-domain --local-config vercel.rice.json` using the existing heavymetalindex project and team. Inspect and verify the staged build before promotion. Environment files and credentials remain ignored and must never be committed.

The contract compiler is the sole writer of adopted manuscripts. Legacy generators now respect that ownership. Other two pilot families remain internal support and regression fixtures; they are not adopted or published by this release.
