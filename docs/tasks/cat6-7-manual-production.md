## Manual assembly (mechanical — generators exist; Codex-able)

The manual is 6 parts; Parts 1, 2, 2.5, 4, 5 are the SAME program text as Cat 1
(reuse from standards-book/parts/) — only the category specifics change. Part 3
(The Standards) is per-row and category-specific.

1. Per Cat 6/7 row, create a Standards Briefing in `data/workbench/briefings/`
   matching the existing 15 Cat 1 briefings' schema, with the master limit table
   from cat{6,7}-standards-tables.md, per-analyte basis/rationale/confidence, a
   sources-cited block, and a provenance footer. (The table data is done; this is
   formatting it into the briefing template.)
2. `node tools/standards/render-part3-chapter.mjs` turns each briefing into a
   Part 3 chapter (adds toxicology callouts, cross-refs, firewall scrub).
3. Stand up `data/workbench/standards-book-cat7/` (and -cat6) reusing Parts 1,2,
   2.5,4,5 from the Cat 1 book with category-name swaps; drop the new Part 3
   chapters in.
4. `node tools/standards/build-program-manual.mjs` → master markdown;
   `--pdf` → bound PDF via the Typst pipeline (render-manual-typst.mjs).
